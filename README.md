# LevelEditor
A Work In Progress personal project of a Standalone 3D Level Editor.
I always wanted to learn graphics programming while strengthening my exisiting technical design and programming skills! 

The Stacks:
C++, CMake, SDL3, GLM, Dear IMGUI, and Direct3D 11 are used. 

The Plan:
- The editor will have a dockable interface containing a Scene Hierarchy, 3D Viewport, Inspector, and Asset Browser. 
- It must include entity and component management, transform editing, object selection, editor camera, transform gizmos, level serialization, undo and redo, and drag-and-drop asset placement.
